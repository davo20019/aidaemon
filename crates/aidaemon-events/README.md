# aidaemon-events

**Tier: internal.** Internal to aidaemon, no stability promise. Published only because the daemon depends on it; do not build on it.

The immutable event store, its payloads and the run aggregate, on a host's SQLite pool. Used by the aidaemon daemon.

Part of the [aidaemon SDK](https://github.com/davo20019/aidaemon) (shared version 0.20.0). MIT licensed. Docs: https://docs.rs/aidaemon-events
