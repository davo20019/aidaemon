# aidaemon-decisions

**Tier: internal.** Internal to aidaemon, no stability promise. Published only because the daemon depends on it; do not build on it.

Decision backends that answer closed questions (yes/no, one of N, a score) with a confidence and its source. Used by the aidaemon daemon.

Part of the [aidaemon SDK](https://github.com/davo20019/aidaemon) (shared version 0.20.0). MIT licensed. Docs: https://docs.rs/aidaemon-decisions
