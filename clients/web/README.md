# AIdaemon web client

A small browser client for the Client Gateway, served by the gateway itself at `/client/v1/app` (the built files live in `crates/aidaemon-client-gateway/web/` and are compiled into the daemon).

- Pairs the browser with a P-256 key generated by WebCrypto (not extractable, kept in IndexedDB): open the link `/pair_device` (or `aidaemon pair`) gives, or run `aidaemon web` to open it on this machine, enter the code and a name, and confirm in the chat you asked from.
- Signs in on each connection with a signed challenge for a 15-minute token; speaks the client protocol over a WebSocket; resumes from the last event after a reconnect.
- Sessions, chat with live status, approval cards with the choices the chat offers, running work with cancel, `/stop` and other slash commands.

The protocol types (`src/protocol.ts`) are generated from `schemas/client-protocol/v1.schema.json`:

```sh
npm install
npm run gen     # regenerate src/protocol.ts from the schema
npm run build   # type-check, compile and copy into the gateway crate
```

Run it against a daemon with `[client_gateway] enabled = true`, at `http://127.0.0.1:8788/client/v1/app`, or through your own HTTPS tunnel (set `public_url` so pairing links point there).
